# Zant-LLM Boundary v0.1

v0.1 is only an initial branch file set.

Allowed:

- repository bootstrap;
- seed data;
- schema validation;
- template baseline output;
- evaluation/report templates;
- training-lane preparation.

Forbidden:

- connecting to `aiant-zant` runtime;
- changing provider registry;
- enabling provider dispatch;
- route/fetch decisions;
- runtime authority;
- worker activation;
- writeback execution.
